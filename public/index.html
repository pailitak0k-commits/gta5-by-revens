Stuck at 66%?

In Chrome, open chrome://settings/system, turn on Use graphics acceleration when available, then click Relaunch. Edge uses the same setting path and may need a browser restart after changing it.

01 / Windows

Download. Launch. Play.

  1. Extract the installer ZIP completely.
  2. Run Download-Game.cmd. Keep the window open until it finishes.
  3. Run Launch-Local.cmd and open the local address in Chrome or Edge.

02 / Mac · Experimental gameplay

A native launch path.

  1. Install Python 3.11 or newer and extract the installer ZIP.
  2. Run bash Download-Game.command.
  3. Run bash Launch-Local.command.

03 / Troubleshooting

Sound and map, but a black world?

After starting the local server, try the lower-memory launch link before you change anything else. If the server is already running, open the same origin in a new tab and reload the page.

Already installed?

Keep your existing game files. Download the latest installer ZIP and copy its helper files and support folder into your existing installation, replacing old helpers. Your saves stay in the same browser profile if you keep the same origin.
